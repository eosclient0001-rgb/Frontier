# Scratchpad — transient experiments, never tracked

One-off probes, crops, dumps, and try-outs live here while they are being
used and are deleted when they stop. Nothing in this folder is committed
except this note (the `.gitignore` beside it sees to that).

Things that graduate: harnesses move to `Tests/Proof/<topic>/`, kept sheets
move to `Tests/VisualProofs/<topic>/`.
