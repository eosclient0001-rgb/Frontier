# Rocky cliff: photoscan-style PBR texture and viewer

A rock texture set, generated by a script, and a small three.js viewer that puts it on a cliff so you can inspect the detail up close and in raking light.

> **This is not a real photoscan.** No scanner or photo capture is involved. `generator/generate_rocky_cliff.py` synthesises a surface that carries what a photogrammetry capture gives you: real-scale micro relief, joints and bedding, weathering pits, mineral grain and colour variation with no baked lighting. It writes albedo, normal, roughness, AO and height maps that agree with each other. To use a real scan instead, see [Using a real scan](#using-a-real-scan).

## Layout

```
rocky-cliff/
├── generator/
│   ├── generate_rocky_cliff.py        texture generator (numpy, SciPy, Pillow)
│   └── requirements.txt
└── viewer/
    ├── index.html, vite.config.js, package.json
    ├── src/main.js                    scene, materials, UI
    ├── src/cliffGeometry.js           cliff profile → displaced mesh, UVs in metres
    └── public/textures/rocky-cliff/   the generated 2048 px set (13 MB)
```

## Quick start

**Viewer** (tested with Node 22 and npm 10):

```bash
cd rocky-cliff/viewer
npm install
npm run dev          # serves on 0.0.0.0:5173, open http://localhost:5173
```

`npm run build` produces a static bundle in `dist/`. `npm run preview` serves it.

**Regenerate the textures** (tested with Python 3.11, numpy 2.4, Pillow 12.3, SciPy 1.17):

```bash
cd rocky-cliff/generator
pip install -r requirements.txt
python3 generate_rocky_cliff.py      # writes to ../viewer/public/textures/rocky-cliff/
```

At 2048 px this takes about 20 s on a 2-CPU machine.

## Generator options

| Option | Default | Meaning |
|---|---|---|
| `--size` | 2048 | Texture size in pixels. Must be a power of two, 256 or more. |
| `--seed` | 7 | Same seed and options give identical files (checked by running twice). |
| `--tile-m` | 3.0 | Metres of cliff covered by one tile. The viewer's `TILE_M` must match. |
| `--relief-m` | 0.35 | Height range in metres that `height` and the normal map represent. The viewer's `RELIEF_M` must match. |
| `--normal-format` | `jpg` | `jpg` (quality 95, about 7 MB at 2048) or `png` (lossless, about 11 MB). |
| `--out` | viewer texture folder | Output folder. |
| `--prefix` | `rocky_cliff` | File name prefix. |

## Output maps

| File | Format | Contents |
|---|---|---|
| `rocky_cliff_albedo.jpg` | sRGB | Base colour: bedding, rust, varnish, lichen and dust. Cavity shading is kept mild, so the lighting stays in the other maps. |
| `rocky_cliff_normal.jpg` | tangent space | OpenGL convention: green = +V = up. `nx = -dH/dcol`, `ny = +dH/drow`, `nz = 1`. |
| `rocky_cliff_roughness.jpg` | linear grey | About 0.45 to 1.0. Rougher on pits and cracks. |
| `rocky_cliff_ao.jpg` | linear grey | Cavity and height occlusion, 0.18 to 1.0. |
| `rocky_cliff_height.png` | 8-bit linear | 0 = lowest, 255 = highest. Spans `--relief-m` metres. |

Row 0 is the top of the cliff. Every map is periodic, so the set tiles seamlessly. On the 2048 px set, the mean difference across the wrap edge is at most 1.15 times the mean difference between neighbouring pixels, on every map.

## Viewer

- **Views:** Lit (the full PBR material with displacement), or one map at a time unlit: Albedo, Normal, AO, Rough, Height.
- **Cameras:** Overview, Close-up (the default), Ground. The camera flies between them. Drag to orbit, right-drag to pan, scroll to zoom.
- **Controls:** tile size (1 to 8 m), normal strength, AO strength, relief (scales the geometry displacement), sun angle and height, shadows, and "Break up tiling".
- **Break up tiling:** over large patches, the albedo blends in a second sample at a different scale. This stops the 3 m tile reading as a regular grid. It reduces the repeat but does not remove it.

## Limits

- The 3 m tile repeats across the 40 m wall. Some repetition is still visible in the overview, and the close-up is where the detail reads best. For a production asset, use a larger tile or several distinct tiles.
- The normal map is JPEG by default. Use `--normal-format png` for a lossless normal map.
- The cliff is a single extruded profile with noise. It has no overhangs, boulders or fracture planes.
- Generation was tested at 512, 1024 and 2048 px. 4096 px was not tested, because the sandbox has about 4 GB of RAM.
- The headless browser check used software WebGL (SwiftShader). Frame rate will be much higher on a real GPU.

## Using a real scan

1. Put the scan's maps in `viewer/public/textures/rocky-cliff/` with the same file names (or change `FILES` in `viewer/src/main.js`).
2. If the scan's normal map uses the DirectX convention (green = down, as Unreal-style exports do), flip it: set `normalScale.y = -1` on the lit material in `viewer/src/main.js`.
3. Set `RELIEF_M` to the real height range of the scan's height map, in metres, and `TILE_M` to the real size of one tile.

Scans from CC0 libraries can be used freely. Check each source's licence before you add its files to a repository.
