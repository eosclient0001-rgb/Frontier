# Frontier

## Rocky cliff: procedural PBR rock texture and viewer

A photoscan-style rock texture set, generated by a script, and a Three.js viewer that shows it on a cliff so the detail can be inspected close up and in raking light. The textures are procedural, not a real scan. See [rocky-cliff/README.md](rocky-cliff/README.md) for the details.

```bash
cd rocky-cliff/viewer
npm install
npm run dev            # then open http://localhost:5173
```

To regenerate the maps:

```bash
cd rocky-cliff/generator
pip install -r requirements.txt
python3 generate_rocky_cliff.py
```
