# Frontier

Experimental browser studies reconstructed from the linked `SultanAladin/Frontier-` branch:

- [IlluminationHost-Prototype](Experimental/IlluminationHost-Prototype/README.md) — pre-C++ WebGPU proving grounds, ReSTIR GI and the live in-car Garage HMI. [Next iteration plan](Experimental/IlluminationHost-Prototype/NEXT_STEPS.md).
- [interactive-vehicle-hmi-configurator](Experimental/interactive-vehicle-hmi-configurator/) — independent React/Three.js configurator retained as a reference for the Garage appearance and ghost controls.

These are separate prototypes; the React app is not the WebGPU vehicle renderer. No patch files are required.
