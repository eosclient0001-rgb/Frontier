# Frontier

## ocean.html — real-time open-ocean simulation

Single self-contained file (raw WebGL2, zero dependencies). Open it in any
recent browser with hardware acceleration — no build step, no server needed.

- Tessendorf GPU-FFT waves, 2 cascades on incommensurate tiles (480 m / 97.3 m)
- Jacobian whitecaps + persistent advected foam, 4096 spray + 1536 splash particles
- Exact Fresnel, sun glitter, crest subsurface scattering, procedural sky, ACES
