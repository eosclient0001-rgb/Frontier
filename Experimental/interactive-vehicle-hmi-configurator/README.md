# Interactive Vehicle HMI Configurator

A standalone React, Three.js and React Three Fiber design study for configuring an interactive vehicle HMI. It includes draggable paint/wheel choices, gloss and matte finishes, a scan/ghost effect, and a wireframe-style scan overlay.

```sh
npm ci
npm run dev -- --host 0.0.0.0
```

The standalone page renders its own illustrative truck model. The live material controls requested for the actual ControlVehicle are integrated into the Garage application in [`../IlluminationHost/README.md`](../IlluminationHost/README.md).
