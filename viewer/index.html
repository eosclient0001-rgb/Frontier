Geological pipeline

  1. 1 · Base SDF — tapered hoodoo / mesa slab / spire cone / cliff wall / column field / dome; never a linear extrusion.
  2. 2 · Strata & hardness — Claron / Wingate / basalt column: per-layer hardness 0.28–0.93, cross-bed laminae, cement patches.
  3. 3 · Tectonic warps — fold, tilt (dip 4–12°), fault throw, domain warp → beds are never flat.
  4. 4 · Case hardening — 1–4 cm silica/iron crust near surface boosts hardness +0.20; broken where salt breaches.
  5. 5 · Differential erosion — rate ∝ (1−H)^1.8 → cliff-and-bench stairsteps, basal sapping alcoves.
  6. 6 · Hydraulics & aeolian — rills (flow accumulation), fluting (windward dot(normal,wind)), talus 32° cone.
  7. 7 · Joints — orthogonal sets (2.2–4.5 m) or centroidal Voronoi hex colonnade CV≈0.36 + hackly entablature + striae.
  8. 8 · Weathering — honeycomb tafoni via Voronoi pits (salt crystallization), frost wedging at top, exfoliation sheets.
  9. 9 · Marching Cubes — 110–270³ grid (longest axis 220), chunked sampling, vertex hardness color (no texture maps).

Research: Mesa/butte differential erosion (NPS, Livescience), Baihetan CV columnar jointing (Di et al. 2018), VSRD pentagon control (2025), Bryce hoodoo Claron Fm. (Utah GS), tafoni case-hardening (Mol & Viles 2010, ERT).

CLI usage

pip install -r requirements.txt  # numpy scipy scikit-image trimesh

# single formation high-res (longest axis 220)
python -m frontier.cli --preset hoodoo_bryce --resolution 220

# all 7 presets at preview res
python -m frontier.cli --all --resolution 140

# list genetics
python -m frontier.cli --list

# outputs → output/*.glb + *.ply (vertex color) + *.obj + *_meta.json

Start viewer: python -m http.server 8000 then open viewer/.
